## Page 1

Backend  Requirement
Learner need to design a Backend for the admin so that admin can have a control over the content
management of all the content on the Home page.
Content include change in textual content, image content etc.
Following backend show is a reference backend Dashboard shown to the admin.
Admins must login with its credentials to access the dashboard.
Backend Dashboard
Manage Image Slider
If there is need to change the images in the slider, Admin must click on the manage image slider button
and then it will direct the admin to Manage Image slider Dashboard. Where admin will get a provision to
add an image and to update an existing image.
